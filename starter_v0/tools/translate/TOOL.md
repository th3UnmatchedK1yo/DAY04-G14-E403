# Tool: translate

## When to use
- Use when user wants to translate text from one language to another.
- Do not use if user only asks for the meaning of a slang word (use lookup).

## Parameters
- `text` (string): The text to be translated. Required.
- `target_language` (string): The target language to translate to. Default is "Vietnamese".
